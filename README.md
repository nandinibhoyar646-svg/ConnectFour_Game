# Connect Four Game

A simple **console-based Connect Four game developed using Java** for two players.

## Features

* Two-player gameplay
* 6 × 7 game board
* Automatic piece placement
* Horizontal, vertical, and diagonal win detection
* Full-column validation
* Draw detection
* Simple console interface

##  Technologies Used

* Java
* 2D Arrays
* Loops
* Conditional Statements
* Methods
* Scanner for user input

##  How to Play

1. Player 1 uses **X** and Player 2 uses **O**.
2. Select a column from **1 to 7**.
3. The piece automatically falls to the lowest available position.
4. Connect four pieces horizontally, vertically, or diagonally to win.
5. If the board becomes full without a winner, the game ends in a draw.

## How to Run

Compile and run:

```bash
javac ConnectFour.java
java ConnectFour
```
